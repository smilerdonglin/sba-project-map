# SBA Project map (public view)

View-only map of the small manufacturers in HUBZone and high-unemployment areas of Oregon, Washington,
Idaho, Nevada and California for the PACNW-iAM SBA Project. Built from the team's map template; the
working copy with outreach records lives in the team's Box folder, not here.

Served by GitHub Pages and embedded at https://manufacturing.oregonstate.edu/education/sba-project.
Rebuild: `node build-public.mjs` in the Box `Map website/site` folder, then copy `public-site/` here and push.
